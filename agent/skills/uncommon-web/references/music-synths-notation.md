# Music, synths & notation

Trackers, bytebeat, chiptune composers, vocal-tract synthesis, sheet music and guitar tabs. Everything audible, synthesized in the tab.

28 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **BassoonTracker**: A full Amiga ProTracker/FastTracker clone running in plain JS `npm i github:steffest/BassoonTracker` · MIT v0.5.0.8 (f2d3a10) · [source](https://github.com/steffest/BassoonTracker) · [demo](https://webdev.teknium.io/d/music2/demos/bassoontracker-amiga-mod/)
- **BeepBox**: The beepbox.co chiptune synth and song format, as a library `npm i beepbox` · MIT v4.2.0 · [source](https://github.com/johnnesky/beepbox) · [demo](https://webdev.teknium.io/d/music2/demos/beepbox-chiptune-grid/)
- **html5bytebeat**: One-line math expressions of t rendered as 8 kHz audio `npm i github:greggman/html5bytebeat` · MIT v2.0.0 (a266d2f) · [source](https://github.com/greggman/html5bytebeat) · [demo](https://webdev.teknium.io/d/music2/demos/bytebeat-formula-lab/)
- **NexusUI**: Classic canvas/SVG widget set for Web Audio instruments `npm i nexusui` · MIT v2.1.6 · [source](https://github.com/nexus-js/ui) · [demo](https://webdev.teknium.io/d/music2/demos/nexusui-instrument-panel/)
