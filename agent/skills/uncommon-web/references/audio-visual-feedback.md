# Audio-visual & feedback

Music visualizers, video-feedback loops and iridescent shader chains. The net-art lineage of MilkDrop and the demoscene, running in a browser tab.

13 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **Butterchurn**: Winamp's MilkDrop 2 visualizer, reimplemented in WebGL `npm i butterchurn butterchurn-presets` · MIT v2.6.7 · [source](https://github.com/jberg/butterchurn) · [demo](https://webdev.teknium.io/d/av/demos/butterchurn-milkdrop/)
- **regl**: Functional, stateless WebGL with declarative draw commands `npm i regl` · MIT v2.1.1 · [source](https://github.com/regl-project/regl) · [demo](https://webdev.teknium.io/d/av/demos/regl-iridescent-puddle/)
- **shader-doodle**: A web component for Shadertoy-style multipass shaders `npm i shader-doodle@1.0.0-alpha.22` · MIT v1.0.0-alpha.22 · [source](https://github.com/halvves/shader-doodle) · [demo](https://webdev.teknium.io/d/av/demos/shader-doodle-audio/)
- **three.js**: The standard 3D library for the web, with physical materials `npm i three` · MIT v0.186.1 · [source](https://github.com/mrdoob/three.js) · [demo](https://webdev.teknium.io/d/av/demos/three-iridescence-foil/)
- **wavesurfer.js**: Interactive, customizable audio waveforms for the browser `npm i wavesurfer.js` · BSD-3-Clause v8.0.3 · [source](https://github.com/katspaugh/wavesurfer.js) · [demo](https://webdev.teknium.io/d/av/demos/wavesurfer-regions/)
- **glitch-canvas**: Glitches images by corrupting their JPEG bytes `npm i glitch-canvas` · MIT v1.1.12 · [source](https://github.com/snorpey/glitch-canvas) · [demo](https://webdev.teknium.io/d/av/demos/glitch-canvas-datamosh/)
- **VEDA.js**: Shader-art framework for VJing: multipass GLSL, sound shaders `npm i vedajs` · MIT v0.17.0 · [source](https://github.com/fand/vedajs) · [demo](https://webdev.teknium.io/d/av/demos/vedajs-scope-music/)
- **woscope**: WebGL oscilloscope emulator: XY audio drawn as a glowing analog beam `npm i github:m1el/woscope#74af1e3` · MIT v0.2.2 (74af1e3) · [source](https://github.com/m1el/woscope) · [demo](https://webdev.teknium.io/d/av2/demos/woscope-vector-art/)
- **Webvs**: Winamp's Advanced Visualization Studio, ported to WebGL `npm i webvs` · MIT v3.0.0 · [source](https://github.com/azeem/webvs) · [demo](https://webdev.teknium.io/d/av2/demos/webvs-avs-presets/)
- **DSSSP**: React SVG components for audio EQs and filter-response graphs `npm i dsssp` · MIT v0.8.0 · [source](https://github.com/NumberOneBot/dsssp) · [demo](https://webdev.teknium.io/d/av2/demos/dsssp-parametric-eq/)
- **SiriWave**: Apple's Siri waveform, iOS 9 and classic, on canvas `npm i siriwave` · MIT v2.4.0 · [source](https://github.com/kopiro/siriwave) · [demo](https://webdev.teknium.io/d/av2/demos/siriwave-voice-orb/)
- **Audio Borealis**: A sound-reactive aurora that rises from a box's bottom edge `npm i @daformat/audio-borealis` · 0BSD v1.0.1 · [source](https://github.com/daformat/audio-borealis) · [demo](https://webdev.teknium.io/d/av2/demos/audio-borealis-voice-card/)
- **html-midi-player**: Web components that play and draw MIDI: piano-roll, waterfall, staff `npm i html-midi-player` · BSD-2-Clause v1.6.0 · [source](https://github.com/cifkao/html-midi-player) · [demo](https://webdev.teknium.io/d/av2/demos/html-midi-player-visualizers/)
