# Scroll, pages & transitions

Page curls, origami folds, zooming interfaces, scrollytelling and the 23 Internet Explorer transitions, reborn. How one view becomes the next.

16 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **pushIn.js**: Scroll-driven camera dolly that pushes layers past the viewer `npm i pushin` · MIT v6.0.1 · [source](https://github.com/nateplusplus/pushin) · [demo](https://webdev.teknium.io/d/flow2/demos/pushin-dolly-flythrough/)
- **React Kino**: Cinematic scroll-driven storytelling components for React `npm i react-kino` · MIT v0.6.0 · [source](https://github.com/btahir/react-kino) · [demo](https://webdev.teknium.io/d/flow2/demos/react-kino-cinematic-launch/)
- **r3f-scroll-rig**: Tracks DOM elements and draws R3F meshes in their place `npm i @14islands/r3f-scroll-rig` · ISC v8.15.0 · [source](https://github.com/14islands/r3f-scroll-rig) · [demo](https://webdev.teknium.io/d/flow2/demos/r3f-scroll-rig-ripple-gallery/)
- **impress.js**: Prezi-style presentations from CSS 3D transforms `npm i impress.js` · MIT v1.1.0 · [source](https://github.com/impress/impress.js) · [demo](https://webdev.teknium.io/d/flow2/demos/impress-3d-tour/)
- **SSGOI**: Native-app page transitions for the web, on spring physics `npm i @ssgoi/react` · MIT v7.4.1 · [source](https://github.com/meursyphus/ssgoi) · [demo](https://webdev.teknium.io/d/flow2/demos/ssgoi-phone-transitions/)
- **transition.css**: Drop-in clip-path transitions triggered by one HTML attribute `npm i transition-style` · ISC v0.1.4 · [source](https://github.com/argyleink/transition.css) · [demo](https://webdev.teknium.io/d/flow2/demos/transition-style-wipe-gallery/)
- **OriDomi**: Fold live DOM elements like paper with CSS 3D transforms `npm i oridomi` · MIT v1.1.2 · [source](https://github.com/dmotz/oriDomi) · [demo](https://webdev.teknium.io/d/flow2/demos/oridomi-paper-folds/)
- **Peel.js**: Corner-peel effect for HTML elements using SVG clip paths `curl -LO https://raw.githubusercontent.com/andrewplummer/peel-js/master/src/peel.js` · MIT vmaster@f6848d2 · [source](https://github.com/andrewplummer/peel-js) · [demo](https://webdev.teknium.io/d/flow2/demos/peel-js-sticker-sheet/)
- **Swup**: Page transitions for server-rendered multi-page sites `npm i swup @swup/overlay-theme @swup/slide-theme @swup/fade-theme @swup/parallel-plugin` · MIT v4.10.0 · [source](https://github.com/swup/swup) · [demo](https://webdev.teknium.io/d/flow3/demos/swup-theme-transitions/)
- **StPageFlip**: Realistic page-curl flipbooks from HTML pages or images `npm i page-flip` · MIT v2.0.7 · [source](https://github.com/Nodlik/StPageFlip) · [demo](https://webdev.teknium.io/d/flow3/demos/stpageflip-zine/)
- **IE Page Transitions**: Internet Explorer's Page-Enter meta transitions, rebuilt on View Transitions `npm i ie-page-transitions` · MIT v1.0.0 · [source](https://github.com/bramus/ie-page-transitions) · [demo](https://webdev.teknium.io/d/flow3/demos/ie-revealtrans-revival/)
- **Scrollama**: Scrollytelling with IntersectionObserver: sticky graphic, scrolling steps `npm i scrollama` · MIT v3.2.0 · [source](https://github.com/russellgoldenberg/scrollama) · [demo](https://webdev.teknium.io/d/flow3/demos/scrollama-sticky-story/)
- **lax.js**: Tiny scroll animation library driven by position and velocity `npm i lax.js` · MIT v2.0.3 · [source](https://github.com/alexfoxy/lax.js) · [demo](https://webdev.teknium.io/d/flow3/demos/lax-velocity-poster/)
- **Lottie + lottie-interactivity**: Scroll- and cursor-synced playback for Lottie animations `npm i lottie-web @lottiefiles/lottie-interactivity` · MIT v1.6.2 · [source](https://github.com/LottieFiles/lottie-interactivity) · [demo](https://webdev.teknium.io/d/flow3/demos/lottie-scroll-scrub/)
- **Zumly**: Zooming user interfaces: navigate in depth, not pages `npm i zumly` · MIT v0.97.0 · [source](https://github.com/zumerlab/zumly) · [demo](https://webdev.teknium.io/d/flow3/demos/zumly-zoom-dive/)
- **Vue Flux**: Vue 3 image slider with 20 built-in 2D and 3D transitions `npm i vue-flux` · MIT v7.1.2 · [source](https://github.com/ragnarlotus/vue-flux) · [demo](https://webdev.teknium.io/d/flow3/demos/vue-flux-transitions/)
