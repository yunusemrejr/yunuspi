# Typography & text

Text laid out without the DOM, split into glyphs, scrambled, hand-annotated and written out stroke by stroke.

50 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.
