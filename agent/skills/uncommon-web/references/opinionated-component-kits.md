# Opinionated component kits

shadcn-compatible registries with a strong visual identity: 8-bit, neo-brutalist, physics-driven typography, interfaces with sound.

39 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.
