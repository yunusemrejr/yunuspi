# Data, maps & graphs as art

Globes with flight arcs, million-node GPU graphs, exotic map projections, wind maps and fantasy cartography.

13 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **Globe.gl**: Three.js globe component for arcs, hexbins, rings and labels `npm i globe.gl` · MIT v2.46.2 · [source](https://github.com/vasturiano/globe.gl) · [demo](https://webdev.teknium.io/d/viz2/demos/globe-gl-night-flights/)
- **cosmos.gl**: Force-directed graph layout and rendering done entirely on the GPU `npm i @cosmos.gl/graph` · MIT v3.5.1 · [source](https://github.com/cosmosgl/graph) · [demo](https://webdev.teknium.io/d/viz2/demos/cosmos-gl-gpu-galaxy/)
- **deck.gl**: GPU-powered layers for large-scale geospatial visualization `npm i @deck.gl/core @deck.gl/layers @deck.gl/geo-layers @deck.gl/aggregation-layers` · MIT v9.4.0 · [source](https://github.com/visgl/deck.gl) · [demo](https://webdev.teknium.io/d/viz2/demos/deck-gl-trips-city-pulse/)
- **3d-force-graph**: 3D force-directed graph component on three.js and d3-force-3d `npm i 3d-force-graph` · MIT v1.80.1 · [source](https://github.com/vasturiano/3d-force-graph) · [demo](https://webdev.teknium.io/d/viz2/demos/force-graph-3d-neural-bloom/)
- **Sigma.js**: WebGL graph renderer built on graphology `npm i sigma graphology graphology-layout-forceatlas2` · MIT v4.0.3 · [source](https://github.com/jacomyal/sigma.js) · [demo](https://webdev.teknium.io/d/viz2/demos/sigma-dependency-atlas/)
- **textures.js**: SVG pattern fills for data visualization `npm i textures` · MIT v1.2.3 · [source](https://github.com/riccardoscalco/textures) · [demo](https://webdev.teknium.io/d/viz2/demos/textures-js-riso-atlas/)
- **d3-voronoi-treemap**: D3 plugin computing treemaps from weighted Voronoi tessellations `npm i d3-voronoi-treemap` · BSD-3-Clause v1.1.2 · [source](https://github.com/Kcnarf/d3-voronoi-treemap) · [demo](https://webdev.teknium.io/d/viz2/demos/voronoi-treemap-world-economy/)
- **d3-geo-projection**: Over 100 extra map projections for d3-geo, plus polyhedral friends `npm i d3-geo-projection d3-geo-polygon d3-geo` · ISC v4.0.0 · [source](https://github.com/d3/d3-geo-projection) · [demo](https://webdev.teknium.io/d/viz3/demos/geo-projection-morph/)
- **webgl-wind**: GPU particle wind visualization, all state in WebGL textures `npm i github:mapbox/webgl-wind#b1f6468` · ISC vb1f6468 · [source](https://github.com/mapbox/webgl-wind) · [demo](https://webdev.teknium.io/d/viz3/demos/webgl-wind-gfs-streaks/)
- **mapgen4**: Red Blob Games' real-time procedural wilderness map generator `git clone https://github.com/redblobgames/mapgen4 && cd mapgen4 && ./build.sh` · Apache-2.0 vc1d8cb0 · [source](https://github.com/redblobgames/mapgen4) · [demo](https://webdev.teknium.io/d/viz3/demos/mapgen4-painted-island/)
- **d3-graphviz**: Graphviz DOT rendered to SVG with animated D3 transitions `npm i d3-graphviz d3` · BSD-3-Clause v5.6.0 · [source](https://github.com/magjac/d3-graphviz) · [demo](https://webdev.teknium.io/d/viz3/demos/graphviz-dot-morph/)
- **MathBox**: Presentation-quality WebGL math graphing on three.js `npm i mathbox three` · MIT v2.3.2-rc1 · [source](https://github.com/unconed/mathbox) · [demo](https://webdev.teknium.io/d/viz3/demos/mathbox-complex-surfaces/)
- **ENCOM Globe**: WebGL hex-tile globe from Tron: Legacy's boardroom scene `npm i encom-globe` · MIT v0.5.4 · [source](https://github.com/arscan/encom-globe) · [demo](https://webdev.teknium.io/d/viz3/demos/encom-hex-globe/)
