# Visual effects & generative art

Liquid glass refraction, CSS-only glitch, generative patterns, SDF sculptures and low-poly fields. Effects with a signature look.

15 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **liquid-glass-react**: Apple-style liquid glass React component with real refraction `npm i liquid-glass-react` · MIT v1.1.1 · [source](https://github.com/rdev/liquid-glass-react) · [demo](https://webdev.teknium.io/d/fx/demos/liquid-glass-dock/)
- **Shader Park**: Write raymarched SDF shaders as plain JavaScript `npm i shader-park-core three` · Apache-2.0 v0.2.8 · [source](https://github.com/shader-park/shader-park-core) · [demo](https://webdev.teknium.io/d/fx/demos/shader-park-sdf-sculpture/)
- **PowerGlitch**: Tiny library that glitches any DOM element with pure CSS `npm i powerglitch` · MIT v2.5.0 · [source](https://github.com/7PH/powerglitch) · [demo](https://webdev.teknium.io/d/fx/demos/powerglitch-signal-lost/)
- **Mesh Gradient**: Stripe-style animated WebGL mesh gradients from four colours `npm i @mesh-gradient/core` · MIT v2.0.2 · [source](https://github.com/mikhailmogilnikov/mesh-gradient) · [demo](https://webdev.teknium.io/d/fx/demos/mesh-gradient-silk/)
- **GL Transitions**: Open collection of 100+ GLSL image transitions `npm i gl-transitions gl-transition gl-texture2d` · MIT v1.76.1 · [source](https://github.com/gl-transitions/gl-transitions) · [demo](https://webdev.teknium.io/d/fx/demos/gl-transitions-slideshow/)
- **curtains.js**: Turns DOM images into WebGL planes you can shade `npm i curtainsjs` · MIT v8.1.6 · [source](https://github.com/martinlaxenaire/curtainsjs) · [demo](https://webdev.teknium.io/d/fx/demos/curtains-ripple-gallery/)
- **css-doodle**: Web component that draws generative patterns with CSS grids `npm i css-doodle` · MIT v0.63.0 · [source](https://github.com/css-doodle/css-doodle) · [demo](https://webdev.teknium.io/d/fx/demos/css-doodle-patterns/)
- **blobs**: Seeded random blob shapes that morph smoothly `npm i blobs` · MIT v2.3.0-beta.2 · [source](https://github.com/g-harel/blobs) · [demo](https://webdev.teknium.io/d/fx/demos/blobs-organic-morph/)
- **liquidGL**: Real refractive liquid glass for any DOM element, WebGPU/WebGL `npm i liquid-gl` · MIT v3.0.0 · [source](https://github.com/naughtyduk/liquidGL) · [demo](https://webdev.teknium.io/d/fx2/demos/liquidgl-glass-lens/)
- **VFX-JS**: One call puts WebGL shaders on any img, video or text element `npm i @vfx-js/core` · MIT v1.1.0 · [source](https://github.com/fand/vfx-js) · [demo](https://webdev.teknium.io/d/fx2/demos/vfx-js-glitch-gallery/)
- **three-msdf-text-utils**: MSDF text geometry and materials for three.js, WebGL and WebGPU `npm i three-msdf-text-utils three` · ISC v1.5.0 · [source](https://github.com/leochocolat/three-msdf-text-utils) · [demo](https://webdev.teknium.io/d/fx2/demos/msdf-text-shader-reveal/)
- **glfx.js**: Evan Wallace's WebGL image-effects library with a chainable filter API `npm i glfx` · MIT v0.0.4 · [source](https://github.com/evanw/glfx.js) · [demo](https://webdev.teknium.io/d/fx2/demos/glfx-swirl-lens/)
- **hover-effect**: WebGL displacement-map crossfades between two images on hover `npm i hover-effect` · MIT v1.2.1 · [source](https://github.com/robin-dela/hover-effect) · [demo](https://webdev.teknium.io/d/fx2/demos/hover-effect-seasons/)
- **Kampos**: Tiny WebGL effects compositor for video, images and canvas `npm i kampos` · MIT v0.16.0 · [source](https://github.com/wix-incubator/kampos) · [demo](https://webdev.teknium.io/d/fx2/demos/kampos-duotone-turbulence/)
- **Metal FX**: Liquid-metal WebGL rings, buttons, text and badges for React `npm i metal-fx` · MIT v2.0.11 · [source](https://github.com/Jakubantalik/metal-fx) · [demo](https://webdev.teknium.io/d/fx2/demos/metal-fx-chrome-controls/)
