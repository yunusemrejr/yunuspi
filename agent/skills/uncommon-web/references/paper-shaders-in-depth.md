# Paper Shaders, in depth

One library, many moods: image filters, liquid-metal logos, pulsing borders and god rays. Zero-dependency WebGL shaders built to be dropped into real product UI.

1 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.
