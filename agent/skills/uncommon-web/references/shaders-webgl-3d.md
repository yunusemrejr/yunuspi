# Shaders, WebGL & 3D

Globes, fluid ink, gradients with depth and flat pseudo-3D. GPU backdrops that fit in a hero section.

20 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **Cobe**: A 5 kB WebGL dotted globe with markers and arcs `npm i cobe` · MIT v2.0.1 · [source](https://github.com/shuding/cobe) · [demo](https://webdev.teknium.io/d/gl/demos/cobe-globe-anchors/)
- **Vanta.js**: Animated 3D website backgrounds in a few lines `npm i vanta three@0.134.0` · MIT v0.5.24 · [source](https://github.com/tengbao/vanta) · [demo](https://webdev.teknium.io/d/gl/demos/vanta-effects-switcher/)
- **WebGL Fluid**: ESM port of PavelDoGreat's WebGL fluid simulation `npm i webgl-fluid` · MIT v0.4.0 · [source](https://github.com/cloydlau/webgl-fluid) · [demo](https://webdev.teknium.io/d/gl/demos/webgl-fluid-ink/)
- **ShaderGradient**: Animated, grainy 3D mesh gradients as a React component `npm i @shadergradient/react @react-three/fiber three` · MIT v2.4.20 · [source](https://github.com/ruucm/shadergradient) · [demo](https://webdev.teknium.io/d/gl/demos/shadergradient-presets/)
- **OGL**: Minimal WebGL library with a three.js-like API `npm i ogl` · Unlicense v1.0.11 · [source](https://github.com/oframe/ogl) · [demo](https://webdev.teknium.io/d/gl/demos/ogl-flowmap-poster/)
- **Zdog**: Round, flat pseudo-3D engine for canvas and SVG `npm i zdog` · MIT v1.1.3 · [source](https://github.com/metafizzy/zdog) · [demo](https://webdev.teknium.io/d/gl/demos/zdog-orbit-illustration/)
- **threejs-toys**: Ready-made three.js cursor and background effects `npm i threejs-toys three` · ISC v0.0.8 · [source](https://github.com/klevron/threejs-toys) · [demo](https://webdev.teknium.io/d/gl/demos/threejs-toys-cursors/)
- **tsParticles**: Modular, configurable particle engine, successor to particles.js `npm i @tsparticles/engine @tsparticles/slim` · MIT v4.4.0 · [source](https://github.com/tsparticles/tsparticles) · [demo](https://webdev.teknium.io/d/gl/demos/tsparticles-lowpoly-mesh/)
- **TypeGPU**: Type-safe WebGPU toolkit: typed buffers, layouts and shaders in TypeScript `npm i typegpu` · MIT v0.12.8 · [source](https://github.com/software-mansion/TypeGPU) · [demo](https://webdev.teknium.io/d/gl2/demos/typegpu-boids-flock/)
- **GSS (GPU Style Sheets)**: CSS syntax compiled into a single raymarching shader `npm i gss-lang` · Apache-2.0 v0.0.6 · [source](https://github.com/LukyVj/GSS) · [demo](https://webdev.teknium.io/d/gl2/demos/gss-css-raymarch-editor/)
- **React Fluid Distortion**: Pointer-driven fluid simulation as an R3F post-processing effect `npm i @whatisjery/react-fluid-distortion @react-three/fiber @react-three/drei @react-three/postprocessing postprocessing three` · MIT v1.6.3 · [source](https://github.com/whatisjery/react-fluid-distortion) · [demo](https://webdev.teknium.io/d/gl2/demos/react-fluid-distortion-type/)
- **fireworks-js**: Canvas fireworks with tunable rockets, bursts and trails `npm i fireworks-js` · MIT v2.10.8 · [source](https://github.com/crashmax-dev/fireworks-js) · [demo](https://webdev.teknium.io/d/gl2/demos/fireworks-js-night-harbor/)
- **color4bg**: Animated WebGL hero backgrounds from a palette and a seed `npm i color4bg` · MIT v0.1.1 · [source](https://github.com/winterx/color4bg.js) · [demo](https://webdev.teknium.io/d/gl2/demos/color4bg-ambient-switcher/)
- **Shaders**: 200+ WebGPU shader effects as composable framework components `npm i shaders` · MIT v4.0.5 · [source](https://github.com/shader-effects-inc/shaders) · [demo 1](https://webdev.teknium.io/d/gl3/demos/shaders-com-liquid-hero/) [demo 2](https://webdev.teknium.io/d/gl3/demos/shaders-com-glass-lens/)
- **Shader Lab (basement.studio)**: basement.studio's runtime for layered Shader Lab compositions `npm i @basementstudio/shader-lab three` · Apache-2.0 v3.1.0 · [source](https://github.com/basementstudio/shader-lab) · [demo](https://webdev.teknium.io/d/gl3/demos/shader-lab-dither-crt/)
- **use-shader-fx**: FunTech's hook kit of ready-made shader FX for react-three-fiber `npm i @funtech-inc/use-shader-fx` · MIT v2.0.5 · [source](https://github.com/FunTechInc/use-shader-fx) · [demo](https://webdev.teknium.io/d/gl3/demos/use-shader-fx-fluid-marble/)
- **three.quarks**: Unity Shuriken-style particle system and VFX toolkit for three.js `npm i three.quarks three` · MIT v0.17.1 · [source](https://github.com/Alchemist0823/three.quarks) · [demo](https://webdev.teknium.io/d/gl3/demos/three-quarks-spell-vfx/)
- **three-nebula**: WebGL 3D particle engine for three.js, with JSON-defined systems `npm i three three-nebula` · MIT v13.3.0 · [source](https://github.com/creativelifeform/three-nebula) · [demo](https://webdev.teknium.io/d/gl3/demos/three-nebula-galaxy/)
- **three-raymarcher**: Raymarched SDF boxes, capsules and spheres as a three.js Mesh `npm i three-raymarcher` · MIT v0.4.0 · [source](https://github.com/danielesteban/three-raymarcher) · [demo](https://webdev.teknium.io/d/gl3/demos/three-raymarcher-metaballs/)
- **three-good-godrays**: Raymarched volumetric god rays for three.js, occluded by real shadow maps `npm i three-good-godrays postprocessing three` · Zlib v0.12.1 · [source](https://github.com/ameobea/three-good-godrays) · [demo](https://webdev.teknium.io/d/gl3/demos/good-godrays-lattice/)
