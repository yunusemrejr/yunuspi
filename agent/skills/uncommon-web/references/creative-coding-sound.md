# Creative coding & sound

Sketchbooks, live-coded video synths and music patterns, terminals, tiny game engines and draggable math.

8 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **p5.js**: Processing's creative-coding sketchbook, reborn for the browser `npm i p5` · LGPL-2.1 v2.3.4 · [source](https://github.com/processing/p5.js) · [demo](https://webdev.teknium.io/d/code/demos/p5-flow-field/)
- **Elementary Audio**: Declarative, functional audio DSP: describe the graph, it diffs it `npm i @elemaudio/core @elemaudio/web-renderer @elemaudio/offline-renderer` · MIT v4.0.1 · [source](https://github.com/elemaudio/elementary) · [demo](https://webdev.teknium.io/d/code/demos/elementary-live-patch/)
- **Tone.js**: A Web Audio framework with synths, effects and a musical transport `npm i tone` · MIT v15.1.22 · [source](https://github.com/Tonejs/Tone.js) · [demo](https://webdev.teknium.io/d/code/demos/tone-step-sequencer/)
- **xterm.js**: The terminal emulator inside VS Code, rendered in the browser `npm i @xterm/xterm @xterm/addon-fit` · MIT v6.0.0 · [source](https://github.com/xtermjs/xterm.js) · [demo](https://webdev.teknium.io/d/code/demos/xterm-terminal/)
- **Kaplay**: A playful JavaScript game library built from components `npm i kaplay` · MIT v3001.0.19 · [source](https://github.com/kaplayjs/kaplay) · [demo](https://webdev.teknium.io/d/code/demos/kaplay-runner/)
- **Paper.js**: A vector-graphics scripting framework with a real scene graph `npm i paper` · MIT v0.16.0 · [source](https://github.com/paperjs/paper.js) · [demo](https://webdev.teknium.io/d/code/demos/paper-boolean-blobs/)
- **Pts**: A library for visualizing and expressing ideas through points `npm i pts` · Apache-2.0 v1.0.3 · [source](https://github.com/williamngan/pts) · [demo](https://webdev.teknium.io/d/code/demos/pts-voronoi-glass/)
- **Mafs**: React components for interactive math, rendered as SVG `npm i mafs` · MIT v0.21.0 · [source](https://github.com/stevenpetryk/mafs) · [demo](https://webdev.teknium.io/d/code/demos/mafs-de-casteljau/)
