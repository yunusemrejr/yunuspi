# Hand-drawn & sketchy

Wobbly lines on purpose. Sketch-rendered shapes, charts, UI kits, whiteboards and pressure-sensitive ink.

7 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **Rough.js**: Draw shapes that look hand-sketched, on canvas or SVG `npm i roughjs` · MIT v4.6.6 · [source](https://github.com/rough-stuff/rough) · [demo](https://webdev.teknium.io/d/hand/demos/roughjs-sketch-studio/)
- **Wired Elements**: Hand-drawn UI web components for wireframe-style interfaces `npm i wired-elements` · MIT v3.0.0-rc.6 · [source](https://github.com/rough-stuff/wired-elements) · [demo](https://webdev.teknium.io/d/hand/demos/wired-elements-form/)
- **chart.xkcd**: xkcd-style sketchy charts: line, XY, bar, pie, radar `npm i chart.xkcd` · MIT v2.0.12 · [source](https://github.com/timqian/chart.xkcd) · [demo](https://webdev.teknium.io/d/hand/demos/chart-xkcd-plots/)
- **roughViz**: D3 charts rendered with Rough.js hand-drawn strokes `npm i rough-viz` · MIT v2.0.5 · [source](https://github.com/jwilber/roughViz) · [demo](https://webdev.teknium.io/d/hand/demos/rough-viz-charts/)
- **perfect-freehand**: Turns pointer points into smooth, pressure-sensitive ink outlines `npm i perfect-freehand` · MIT v1.2.3 · [source](https://github.com/steveruizok/perfect-freehand) · [demo](https://webdev.teknium.io/d/hand/demos/perfect-freehand-ink/)
- **Excalidraw**: The hand-drawn whiteboard, as an embeddable React component `npm i @excalidraw/excalidraw react react-dom` · MIT v0.18.1 · [source](https://github.com/excalidraw/excalidraw) · [demo](https://webdev.teknium.io/d/hand/demos/excalidraw-whiteboard/)
- **Vivus**: Animates SVG strokes so illustrations appear to draw themselves `npm i vivus` · MIT v0.4.6 · [source](https://github.com/maxwellito/vivus) · [demo](https://webdev.teknium.io/d/hand/demos/vivus-line-drawing/)
