# Games, consoles & emulators

Fantasy consoles, tiny engines, HyperCard heirs and emulators running public-domain homebrew. Play inside the card.

15 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **Sandspiel**: Rust/wasm falling-sand toy with a WebGL wind simulation `git clone https://github.com/MaxBittker/sandspiel && cd sandspiel/crate && cargo build --target wasm32-unknown-unknown --release && wasm-bindgen --target web --out-dir pkg target/wasm32-unknown-unknown/release/sandtable.wasm` · MIT v9936e06 · [source](https://github.com/MaxBittker/sandspiel) · [demo](https://webdev.teknium.io/d/games2/demos/sandspiel-falling-sand/)
- **binjgb**: Tiny, accurate Game Boy emulator compiled to WebAssembly `curl -LO https://raw.githubusercontent.com/binji/binjgb/16621111ed0ee73bcc45c912a823bcebedcffc0f/docs/binjgb.{js,wasm}` · MIT ROM: Tobu Tobu Girl © Tangram Games, code MIT, assets CC BY 4.0 · v16621111 (main, 2026-09-25) · [source](https://github.com/binji/binjgb) · [demo](https://webdev.teknium.io/d/games2/demos/binjgb-gameboy-dmg/)
- **JSNES**: A NES emulator written in plain JavaScript `npm i jsnes` · Apache-2.0 ROMs: Lawn Mower & Lan Master (Shiru, public domain), RHDE (Damian Yerrick, GNU All-Permissive) · v2.1.0 · [source](https://github.com/bfirsh/jsnes) · [demo](https://webdev.teknium.io/d/games2/demos/jsnes-crt-console/)
- **Decker**: HyperCard-like 1-bit multimedia sketchbook with Lil scripting `git clone https://github.com/JohnEarnest/Decker && cd Decker && make web-decker` · MIT v1.71 (b3c964a) · [source](https://github.com/JohnEarnest/Decker) · [demo](https://webdev.teknium.io/d/games2/demos/decker-hypercard-deck/)
- **Octo**: CHIP-8 / SCHIP / XO-CHIP assembler, IDE and emulator `git clone https://github.com/JohnEarnest/Octo (vendor js/emulator.js + js/shared.js)` · MIT (emulator) CC0 (chip8Archive ROMs) · v76f816c · [source](https://github.com/JohnEarnest/Octo) · [demo](https://webdev.teknium.io/d/games2/demos/octo-chip8-arcade/)
- **Phaser 4**: HTML5 game framework with a new WebGL renderer and filters `npm i phaser` · MIT v4.2.1 · [source](https://github.com/phaserjs/phaser) · [demo](https://webdev.teknium.io/d/games2/demos/phaser4-neon-breakout/)
- **Excalibur**: TypeScript-first 2D game engine for the web `npm i excalibur` · BSD-2-Clause v0.32.0 · [source](https://github.com/excaliburjs/Excalibur) · [demo](https://webdev.teknium.io/d/games2/demos/excalibur-crt-platformer/)
- **SpessaSynth**: SoundFont2/DLS MIDI synthesizer and sequencer in an AudioWorklet `npm i spessasynth_lib` · Apache-2.0 v4.3.14 · [source](https://github.com/spessasus/spessasynth_lib) · [demo](https://webdev.teknium.io/d/games2/demos/spessasynth-midi-rain/)
- **WASM-4**: WebAssembly fantasy console: 160×160 pixels, 4 colours, 64 KB `npm i wasm4` · ISC v2.7.1 · [source](https://github.com/aduros/wasm4) · [demo](https://webdev.teknium.io/d/games3/demos/wasm4-fantasy-console/)
- **TIC-80**: Open-source fantasy computer: 240×136 pixels, 16 colours, Lua `download the HTML player from https://github.com/nesbox/TIC-80/releases (tic80-v1.3-players.tar.gz → lua/tic80.js + tic80lua.wasm)` · MIT v1.3.1 · [source](https://github.com/nesbox/TIC-80) · [demo](https://webdev.teknium.io/d/games3/demos/tic80-fantasy-computer/)
- **Pyxel**: Retro game engine for Python with a Rust core `pip install pyxel` · MIT (Pyodide runtime MPL-2.0) v2.9.9 · [source](https://github.com/kitao/pyxel) · [demo](https://webdev.teknium.io/d/games3/demos/pyxel-retro-python/)
- **Uxn5**: Hundred Rabbits' JS/wasm emulator for the Uxn/Varvara computer `git clone https://git.sr.ht/~rabbits/uxn5` · ISC-style (uxn5); ROMs MIT vgit 4da440f (2026-04-23) · [source](https://git.sr.ht/~rabbits/uxn5) · [demo](https://webdev.teknium.io/d/games3/demos/uxn-varvara-computer/)
- **v86**: x86 PC emulator with an x86-to-WebAssembly JIT `npm i v86` · BSD-2-Clause (SeaBIOS LGPL-3.0; bootOS + games BSD-2-Clause, nanochess) v0.5.472 · [source](https://github.com/copy/v86) · [demo](https://webdev.teknium.io/d/games3/demos/v86-bootos-pc/)
- **PuzzleScript**: A whole puzzle game as one short text file of rules `git clone https://github.com/increpare/PuzzleScript (or File > Export standalone HTML on puzzlescript.net)` · MIT vgit cf0fc1d (2026-10-22) · [source](https://github.com/increpare/PuzzleScript) · [demo](https://webdev.teknium.io/d/games3/demos/puzzlescript-rule-puzzle/)
- **LittleJS**: Tiny, fast WebGL 2D game engine with particles, sound and shaders `npm i littlejsengine` · MIT v1.28.0 · [source](https://github.com/KilledByAPixel/LittleJS) · [demo](https://webdev.teknium.io/d/games3/demos/littlejs-particle-breakout/)
