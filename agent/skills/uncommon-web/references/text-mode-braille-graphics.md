# Text-mode & braille graphics

Character cells as a canvas: braille dots, ASCII playgrounds, roguelike glyph maps, FIGlet banners, and a real Rust TUI compiled to WebAssembly.

20 libraries, from Uncommon Web (webdev.teknium.io, field guide vol. 1, October 2026). Versions are the ones shown there: check the current release before installing.

- **Ratzilla**: Ratatui terminal UIs compiled to WebAssembly for the browser `cargo add ratzilla` · MIT OR Apache-2.0 v0.3.1 · [source](https://github.com/ratatui/ratzilla) · [demo](https://webdev.teknium.io/d/glyph/demos/ratzilla-tui/)
- **dotmax**: Rust crate for high-density braille terminal graphics `cargo add dotmax` · MIT OR Apache-2.0 v0.1.11 · [source](https://github.com/newjordan/dotmax) · [demo](https://webdev.teknium.io/d/glyph/demos/dotmax-wasm/)
- **drawille-canvas**: HTML5 Canvas 2D API that draws in Unicode braille dots `npm i drawille-canvas` · MIT v1.2.1 · [source](https://github.com/madbence/node-drawille-canvas) · [demo](https://webdev.teknium.io/d/glyph/demos/drawille-braille/)
- **rot.js**: Roguelike toolkit: glyph display, map generators, FOV, pathfinding, lighting `npm i rot-js` · BSD-3-Clause v2.2.1 · [source](https://github.com/ondras/rot.js) · [demo](https://webdev.teknium.io/d/glyph/demos/rot-js-dungeon/)
- **textmode.js**: Real-time ASCII and textmode creative coding on a WebGL2 grid `npm i textmode.js` · MIT v0.18.0 · [source](https://github.com/humanbydefinition/textmode.js) · [demo](https://webdev.teknium.io/d/glyph/demos/textmode-js/)
- **play.core**: Andreas Gysin's runtime for ASCII programs written as per-cell functions `git clone https://github.com/ertdfgcvb/play.core` · Apache-2.0 vgit b2d30ac · [source](https://github.com/ertdfgcvb/play.core) · [demo](https://webdev.teknium.io/d/glyph/demos/play-core-ascii/)
- **ascii-magic-art**: 634 animated ASCII art pieces with a player and glyph looks `npm i ascii-magic-art` · MIT v1.0.2 · [source](https://github.com/kailashsr38/ascii-magic-art) · [demo 1](https://webdev.teknium.io/d/glyph/demos/ascii-magic-art-gallery/) [demo 2](https://webdev.teknium.io/d/glyph/demos/ascii-magic-empty-state/)
- **asciichart + figlet**: ASCII line charts and FIGlet banner fonts as plain text `npm i asciichart figlet` · MIT vasciichart 1.5.25 · figlet 1.12.0 · [source](https://github.com/patorjk/figlet.js) · [demo](https://webdev.teknium.io/d/glyph/demos/asciichart-figlet/)
- **cli-spinners**: Sindre Sorhus's JSON collection of 90 terminal loading spinners `npm i cli-spinners` · MIT v3.4.0 · [source](https://github.com/sindresorhus/cli-spinners) · [demo](https://webdev.teknium.io/d/glyph/demos/cli-spinners-gallery/)
- **Matrix digital rain (Rezmason)**: Film-accurate Matrix code rain on WebGL, configured by URL params `git clone https://github.com/Rezmason/matrix` · MIT vgit 5ba9049 · [source](https://github.com/Rezmason/matrix) · [demo](https://webdev.teknium.io/d/glyph2/demos/matrix-digital-rain/)
- **AnsiLove.js**: BBS-era ANSI/XBIN/ADF art rendered to canvas with real CP437 fonts `npm i github:ansilove/ansilove.js` · BSD-2-Clause v1.0.0 (git 056e1f4) · [source](https://github.com/ansilove/ansilove.js) · [demo](https://webdev.teknium.io/d/glyph2/demos/ansilove-bbs-viewer/)
- **glyphcss**: 3D polygon meshes rasterized as text in one <pre> `npm i glyphcss` · MIT v0.3.1 · [source](https://github.com/apresmoi/glyphcss) · [demo](https://webdev.teknium.io/d/glyph2/demos/glyphcss-ascii-3d/)
- **Asciify**: ASCII components, backgrounds and media drawn as GPU characters `npm i asciify-engine` · MIT v4.31.0 · [source](https://github.com/ayangabryl/asciify-engine) · [demo](https://webdev.teknium.io/d/glyph2/demos/asciify-engine-ui/)
- **svgbob (WASM)**: Rust svgbob compiled to WASM: ASCII art in, clean SVG out `npm i svgbob-wasm` · Apache-2.0 v1.0.0 · [source](https://github.com/agoose77/svgbob-wasm) · [demo](https://webdev.teknium.io/d/glyph2/demos/svgbob-live-diagram/)
- **ASCII FX**: Shape-aware ASCII rendering for React, WebGPU with exact CPU fallback `npm i @ascii-fx/react @ascii-fx/core` · MIT v0.8.0 · [source](https://github.com/Amir-Abushanab/ascii-fx) · [demo](https://webdev.teknium.io/d/glyph2/demos/ascii-fx-shape-glyphs/)
- **glyphcast**: WebGL2 video player that redraws every frame as coloured glyphs `npm i glyphcast` · MPL-2.0 v1.5.3 · [source](https://github.com/MrProLopstar/glyphcast) · [demo](https://webdev.teknium.io/d/glyph2/demos/glyphcast-video-glyphs/)
- **The Monospace Web**: CSS that snaps every HTML element to a character grid `npm i @owickstrom/the-monospace-web` · MIT v0.1.5 · [source](https://github.com/owickstrom/the-monospace-web) · [demo](https://webdev.teknium.io/d/glyph2/demos/monospace-web-grid/)
- **crt-terminal**: Retro CRT terminal shell component for React `npm i crt-terminal` · MIT v1.1.3 · [source](https://github.com/essserrr/crt-terminal) · [demo](https://webdev.teknium.io/d/glyph2/demos/crt-terminal-shell/)
- **asciinema-player**: Web player for terminal recordings, rendered as real text `npm i asciinema-player` · Apache-2.0 v3.17.0 · [source](https://github.com/asciinema/asciinema-player) · [demo](https://webdev.teknium.io/d/glyph2/demos/asciinema-player-replay/)
- **@thi.ng/text-canvas**: Text-mode canvas: boxes, clipping, plots, bars and tables `npm i @thi.ng/text-canvas` · Apache-2.0 v3.0.129 · [source](https://github.com/thi-ng/umbrella) · [demo](https://webdev.teknium.io/d/glyph2/demos/thing-text-canvas-dashboard/)
