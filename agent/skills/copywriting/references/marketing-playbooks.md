# Marketing playbooks

Open SKILL.md playbooks by marketers, worth a look on GitHub when a page or an email has to convert. One may raise questions worth asking; keep only the structure that fits the brief, and write the copy by `../SKILL.md`. Checked 27 Nov 2026.

**Rules that win over any playbook:** no invented proof (testimonials, logos, user counts, ratings, "trusted by"), no fake urgency or scarcity, no dark patterns in pop-ups, pricing or cancellation, and no claim the project's own material does not support. Installing a playbook (`npx skills add …`) is the owner's call; reading it is not.

## Corey Haines, marketingskills

`https://github.com/coreyhaines31/marketingskills` (MIT; 53 skills, each a SKILL.md with references; no scripts inside the skills). Raw files: `https://raw.githubusercontent.com/coreyhaines31/marketingskills/main/skills/<name>/SKILL.md`. The README links paid partner tools; the playbooks don't need them.

| The job | Read |
|---|---|
| Landing or product page copy | `copywriting`, `copy-editing`, `product-marketing` |
| A page that should convert better | `cro`, `signup`, `onboarding`, `popups`, `paywalls` |
| Pricing and offers | `pricing`, `offers` |
| "X vs Y" and alternatives pages | `competitors`, `competitor-profiling` |
| Outbound and lifecycle email | `cold-email`, `emails` |
| A launch | `launch`, `marketing-plan` |
| Search | `seo-audit`, `ai-seo`, `schema`, `programmatic-seo`, `site-architecture` |
| Why people decide | `customer-research`, `marketing-psychology` (use the understanding, not the pressure tactics) |
