# Pattern galleries

Real navigation bars, footers and calls to action, indexed by type and by style. Open several that fit the subject before settling on one.

## Navigation: choose the type from the content

| Type | Use when |
| --- | --- |
| Static or sticky bar | Up to about six destinations, no nesting |
| Dropdown | A few parents with short child lists |
| Mega menu | Many destinations in groups (product families, a large store): columns with headings, sometimes one featured item |
| Sidebar | Applications, documentation, anything with deep or long lists |
| Search-led bar | Catalogs and documentation where people arrive knowing what they want |
| Announcement strip | One message above the bar, dismissible |
| Full-screen menu | Brand and portfolio sites with a few large links |
| Breadcrumbs | A second aid in deep hierarchies, never the only navigation |

Count the destinations and their depth, then pick. One primary action sits at the end of the bar. The phone version is designed on its own, not collapsed by default.

Real examples, each with desktop and phone captures: `https://www.navbar.gallery/type/<static|dropdowns|mega-menu|side-bar|search-bar|announcement|full-screen|breadcrumbs>`.

## Footer

The footer is the page's last screen and its map: where to go next (grouped links), who this is (name, legal, contact), and one closing action. It may carry the brand's character: the name set very large, an illustration, a grid. Four identical link columns on a five-page site is filler; size the footer to the site.

Examples by style: `https://www.footer.design/styles/<typographic|large-type|grid|cards|illustrative|small-type>` and `https://www.footer.design/browse`.

## Calls to action

- The button names what the person gets, in their words, and takes a worry away: "Start your free trial", "Download the guide", "Try it free, no card needed". "Submit", "Click here", "Learn more" and a bare "Get started" say nothing.
- A headline above it states the gain. One primary action per view; the second choice is visibly quieter.
- Kinds: button, buy, download, form, newsletter, pricing, dialog. A dialog that interrupts on arrival is out; show it after the person has shown intent.
- Only true promises. "No card needed" appears only when that is so.

Examples: `https://www.cta.gallery/categories/<button|call-to-buy|download|form|newsletter|pricing|modal-pop-up>`.
